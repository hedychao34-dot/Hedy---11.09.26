# Proposal

## Why

製程文件負責人需要辨認可直接沿用的核准譯文與仍需人工判斷的候選。Prototype V1 以一份虛構 PCP 展示繁中轉美式英文的最小流程，供課堂檢視操作與結果一致性。

## What Changes

- 提供桌面瀏覽器互動原型：內建 PCP → 套用核准譯文 → 修改或確認一筆候選 → 英文預覽；具體畫面與資料見 design。
- 核准譯文庫、候選與文件全部是固定虛構資料；套用、編輯、確認、狀態更新與預覽是可操作行為。候選標示「模擬資料」，不呼叫真正翻譯模型。
- Excel 匯入／匯出均不納入；不提供上傳或下載按鈕，不生成 `.xlsx`，英文結果只在畫面預覽。
- 逐步驗收：載入一份 PCP 並看到模擬標示；套用後兩筆核准譯文可辨識；一筆候選可原文確認或修改確認，空白不能確認；預覽反映已確認文字，未確認不混入結果；重設可重新示範。完整條件見 specs 與 e2e-testing。
- 展示說明需揭露上述模擬、Excel 與模型邊界；本次只交付規格，實作與試走須待使用者另行指示。
- 規格審查確認：表格與預覽持續顯示來源及確認狀態，以文字辨識；英文預覽採同頁展開，待確認列保留佔位與數量提示。候選確認文字去除前後空白；依「修改未確認、確認、再次編輯、再次確認」四個狀態驗收。完成只代表本次人工確認流程完成，不自動檢查語言或翻譯品質。

## Capabilities

### New Capabilities

- `process-doc-bilingual-sync`：在固定 PCP 示範中套用核准譯文、人工確認候選並預覽英文結果。

### Modified Capabilities

無；目前主規格庫為空。

## Impact

目前專案只有 OpenSpec 設定與技能，沒有應用程式。後續預計新增 React + Vite、TypeScript strict 的本機前端與虛構 fixture，使用 pnpm；本切片不需要後端、資料庫或外部 API。原型不提供正式文件、PFD、PFMEA、改版同步、自動核准發行或正式資料處理能力。

背景依據為 `.agents/skills/openspec-propose/OpenSpec_作業起步.md`（使用者指定的實際位置）；其中提及的原始 PRD 摘要未提供，不推定已有其他功能。V2、歸檔、部署與 PPT 製作均不在本次交付，未建立任何 V2 需求或驗收結果。
